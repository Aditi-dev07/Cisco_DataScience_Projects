#  Jeans Pockets – Gender-Based Design Data Analysis

##  Project Overview
This project investigates a practical yet overlooked design question:

> **Do women’s jeans really have smaller pockets than men’s jeans?**

Using a real-world dataset of jeans measurements, this analysis compares **pocket dimensions across genders** to uncover design disparities. The project highlights how data analysis can be used to validate everyday experiences and translate them into measurable, data-backed insights.

This notebook demonstrates my ability to clean data, perform comparative analysis, and communicate findings clearly — skills essential for data analyst and data science roles.

---

##  Objectives
- Compare **front and back pocket sizes** between men’s and women’s jeans
- Quantify differences using summary statistics
- Identify whether pocket size disparities are consistent across brands and styles
- Use data to support or challenge common assumptions

---

##  Skills Demonstrated
- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Grouping and aggregation with pandas
- Statistical comparison using descriptive metrics
- Translating real-world questions into data-driven answers

- **Python**

## Dataset
The dataset includes measurements for:
- Front pocket depth and width
- Back pocket depth and width
- Gender classification (Men / Women)
- Brand and style information

These features allow for a detailed comparison of pocket usability across genders.

---

## Analysis Highlights
- Women’s jeans consistently show **smaller pocket dimensions** compared to men’s jeans
- Differences are especially noticeable in **front pocket depth**, affecting real-world usability
- The results support the widely discussed design bias using **quantitative evidence**
