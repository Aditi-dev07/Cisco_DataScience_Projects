# 🟥🟦 Mondrian Art Project – Data-Driven Generative Art Analysis

## 📌 Project Overview
This project combines **art, mathematics, and programming** to recreate and analyze the iconic style of **Piet Mondrian** using data-driven techniques.

> **How can code and structured rules be used to generate art inspired by Mondrian’s geometric compositions?**

Using Python, the notebook applies logical constraints, randomness, and visual structure to generate Mondrian-style artwork. This project highlights creative problem-solving, algorithmic thinking, and the ability to translate artistic rules into reproducible systems.

## 📂 Project Structure
The notebook includes:
- Logic for generating grids and rectangles
- Color assignment based on Mondrian’s palette (red, blue, yellow, black, white)
- Visualization of generated artwork

Each execution can produce a **unique composition**, while still respecting Mondrian’s artistic principles.
