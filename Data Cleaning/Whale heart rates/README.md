# 🐋 Whale Heart Rate Analysis (Python, Pandas, Scientific Data)

## Overview

This project analyzes **whale heart rate data** to understand how heart rate changes under different conditions. The notebook demonstrates how to work with **biological and physiological datasets**, applying data cleaning, aggregation, and interpretation techniques to extract meaningful insights.

The project is structured to be:

* **Learner-friendly**: clear steps and simple explanations
* **Recruiter-oriented**: showcases ability to analyze scientific data using Python

---

## Problem Context

Heart rate data is widely used in:

* Biological and physiological research
* Animal behavior and conservation studies
* Environmental and ecological monitoring

In this project, the analysis focuses on identifying:

* Typical heart rate ranges
* Variations in heart rate across observations
* How summary statistics can describe biological patterns

---

## Dataset

### Source File

* **File name**: `whale-heart-rates.csv`
* **Description**: Contains recorded heart rate measurements of whales

### Key Columns

| Column       | Description                            |
| ------------ | -------------------------------------- |
| `heart_rate` | Recorded heart rate (beats per minute) |

---

## Data Preparation

The dataset requires light but essential preprocessing:

* Load data using pandas
* Ensure heart rate values are numeric
* Handle missing or invalid entries if present

This mirrors real-world scenarios where biological sensor data may be incomplete or noisy.

---

## Analysis Workflow

### 1. Descriptive Statistics

* Calculate:

  * Mean heart rate
  * Median heart rate
  * Standard deviation
* Understand overall distribution of heart rate values

### 2. Distribution Analysis

* Visualize heart rate measurements
* Identify normal ranges and outliers

### 3. Interpretation

* Discuss biological variability in heart rates
* Relate findings to real-world expectations of large marine mammals

---

## Key Insights

* Whale heart rates vary within a measurable range rather than being constant
* Extreme values highlight natural biological variability or measurement noise
* Simple statistical analysis provides meaningful insight into physiological data

## How to Run the Project

1. Clone the repository
2. Ensure Python 3.8+ is installed
3. Install dependencies:

   ```bash
   pip install pandas matplotlib
   ```
4. Place `whale-heart-rates.csv` in the project directory
5. Open and run `whale-heart-rates.ipynb`
