# 🎵 A Century of Top Songs

This project analyzes trends in top-charting songs over the past century using Python and data analysis techniques. The focus is on understanding how song duration has changed over time and identifying notable patterns in popular music history.

The analysis is implemented in a Jupyter Notebook and is intended for exploratory data analysis and learning purposes.

---

## 📌 Project Overview

The main objectives of this project are to:

- Analyze historical top-song data
- Identify the shortest and longest songs in the dataset
- Explore trends in song duration over time
- Practice working with real-world datasets
- Perform data cleaning, inspection, and visualization

---

## 📂 Repository Contents

- **top-songs-project.ipynb**  
  Jupyter Notebook containing the complete analysis, code, and visualizations.

- **top-song-durations.csv**  
  Dataset containing information about top songs, including year, title, artist, and duration.

---

## 🛠️ Technologies Used

- Python 3
- Jupyter Notebook
- pandas
- matplotlib

---

## 📊 Key Findings

- The dataset spans nearly **100 years** of top-charting songs
- The **shortest song** in the dataset is *Sonny Boy* (1928)
- The **top song in 2019** has a duration of 2 minutes and 37 seconds
- Data type inconsistencies were identified and corrected
- Song duration trends were visualized across years
