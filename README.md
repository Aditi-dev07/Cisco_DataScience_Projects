### **Design Philosophy**
"Data doesn't just provide answers—it uncovers the right questions."
- My approach follows a strict "Data-to-Ink" optimization:
- Remove Clutter: No unnecessary spines, ticks, or legends.
- Contextual Benchmarking: Every "large" number is compared to a human-scale reference (e.g., a Jalapeño or a human    breath- hold).
Strategic Color: Using pigment only to highlight the "Main Story."
